  먼저 한 줄. 이 세션에는 이미 claude-in-chrome 도구가 붙어 있어서 클릭,
  스크린샷, 콘솔 로그 확인은 지금도 됩니다. Playwright MCP의 차별점은 사용자
  Chrome 프로필과 분리된 깨끗한 브라우저, 그리고 CI에서도 같은 스크립트를 돌릴
  수 있다는 점입니다. 그게 필요하면 아래 순서로 갑니다.

  적용 순서

  1. MCP 서버 등록 (프로젝트 범위, 팀과 공유)
  claude mcp add --scope project playwright -- npx @playwright/mcp@latest
     레포 루트에 .mcp.json이 생깁니다. 커밋 대상입니다.
  2. 브라우저 바이너리 설치 (1회, 사용자 환경)
  npx playwright install chromium
     규칙 7에 해당하므로 에이전트가 아니라 사용자가 직접 실행합니다.
  3. Claude Code 재시작 후 /mcp로 playwright 연결 확인.
  4. 개발 서버 실행 (사용자가 직접, 규칙 7)
  npm run dev
  5. 점검 요청. "localhost:3000 로그인 화면 점검해줘"처럼 주소와 범위를 주면
     제가 browser_navigate, browser_snapshot, browser_click,
     browser_console_messages로 돌며 개선점을 보고합니다.

  선택 사항

  - --headless 플래그를 add 명령의 npx 뒤에 붙이면 창이 안 뜹니다. 처음에는 창이
    보이는 쪽이 점검 결과를 같이 보기 좋습니다.
  - .mcp.json을 커밋하면 다른 사람도 같은 도구를 쓰므로 AGENTS.md의 명령어 표에
    한 줄 추가가 맞습니다. 규칙 13에 따라 승인 후 같은 PR에서 고칩니다.

  건너뛴 것: @playwright/test 설치와 E2E 테스트 파일. MCP 점검은 패키지 추가
  없이 npx만으로 돌아갑니다. 점검 결과를 회귀 테스트로 고정하고 싶어질 때
  추가합니다.
