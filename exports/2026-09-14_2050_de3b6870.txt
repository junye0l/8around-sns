❯ 궁금한게 세션 대화는 브랜치랑 상관없지?                                       

⏺ 네, 세션 대화와 git 브랜치는 서로 상관이 없습니다.

  - 대화 기록은 git 밖에 있습니다. 세션 대화는 Claude Code가 레포 바깥에 따로
    저장합니다(~/.claude/projects/...). 브랜치를 바꾸거나 지워도 대화 내용은
    그대로 남습니다.
  - 세션이 묶이는 건 폴더입니다. 세션은 브랜치가 아니라 작업 폴더에 붙어
    있습니다. 같은 폴더에서 세션 두 개가 돌면, 둘이 같은 파일과 같은 체크아웃
    상태를 봅니다.

  오늘 제가 메인 트리를 건드리지 않은 이유가 이것입니다.

  - 대화는 안전합니다. 제가 메인 트리에서 브랜치를 바꿔도 리뉴얼 세션의 대화는
    안 날아갑니다.
  - 작업은 흔들립니다. 그 세션이 보고 있는 파일이 바뀌거나 커밋하지 않은 변경이
    섞입니다. 실제로 리뷰 대응 중에 메인 트리가 제가 모르게 다른 브랜치로 바뀌어
    있던 게 이 경우입니다.

  그래서 세션 여러 개를 동시에 돌릴 때는 세션마다 워크트리를 따로 두면 서로
  부딪히지 않습니다.
