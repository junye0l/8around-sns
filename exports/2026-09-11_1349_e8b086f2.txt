  여러분은 이 고객의 요청을 받아 실제 서비스로 출시 가능한 수준의 SNS를 만들고, 
  이후 지속적인 기능 추가와 유지보수가 가능하도록 개발 하네스를 세팅해야        
  합니다.

  3. 요구사항                                                                   
                                                                                
  과제는 크게 두 개의 축으로 구성됩니다. 두 축 모두 필수입니다.                 
                                                                                
  3-1. SNS 프로젝트 (기능 구현)                                                 
                                                                                
  아래 기능은 모두 필수입니다.                                                  
                                                                                
  | 구분 | 기능 | 설명 |                                                        
  |------|------|------|                                                        
  | 계정 | 회원가입 | 신규 사용자 등록 |                                        
  | 계정 | 로그인 | 인증 및 세션 유지 |                                         
  | 소셜 | 팔로우 / 팔로잉 | 다른 사용자 팔로우, 팔로워·팔로잉 목록 확인 |      
  | 콘텐츠 | 게시글 작성 | 게시글 생성 및 피드 노출 |                           
  | 콘텐츠 | 댓글 | 게시글에 댓글 작성 |                                        
  | 콘텐츠 | 대댓글 | 댓글에 답글 작성 (계층 구조) |                            
                                                                                
  디자인 요구사항                                                               
                                                                                
  - AI가 만든 듯한 획일적인 느낌(과도한 그라데이션, 정형화된 카드 레이아웃,     
  의미 없는 장식 등)을 피해 주세요.                                             
  - 깔끔한 레이아웃과 일관된 타이포그래피, 여백을 갖춰야 합니다.                
  - 사용자의 행동에 반응하는 인터랙션(전환, 피드백, 상태 표시 등)이 자연스럽게  
  녹아 있어야 합니다.                                                           
                                                                                
  배포 요구사항                                                                 
                                                                                
  - 실제 접속 가능한 URL로 배포되어야 합니다. (Vercel, Netlify, Cloudflare,     
  AWS, Railway, Fly.io 등 자유)                                                 
  - 심사자가 직접 회원가입 → 로그인 → 게시글 작성 → 댓글/대댓글 → 팔로우 흐름을 
  끝까지 체험할 수 있어야 합니다.                                               
                                                                                
  3-2. 하네스(Harness) 세팅                                                     
                                                                                
  하네스란 개발자(또는 AI 에이전트)가 프로젝트에서 일관된 방식으로, 안정적으로  
  기능을 개발하고 유지보수할 수 있도록 감싸는 개발 환경과 규칙의 집합입니다.    
                                                                                
  단순히 린터를 설치하는 것을 넘어, "이 프로젝트에 새로운 사람이 합류해도 같은  
  품질로 기능을 추가할 수 있는가?" 라는 질문에 답할 수 있어야 합니다.           
                                                                                
  무엇을 어떻게 구성할지는 프로젝트 상황에 맞게 직접 판단해 주세요.
