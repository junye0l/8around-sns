# 디자인 토큰

이 파일이 유일한 출처다. 컴포넌트에 하드코딩된 색·간격·폰트 크기가 보이면 여기로 옮긴다.
값은 **Day 3 AM 디자인 패스에서 한 번에 확정**한다. 그 전까지는 비워둔다 — 기능이 서기 전에 정한 값은 어차피 다시 정한다.

> 상태: 미확정 (Day 3에 채움)

## 1. 타이포그래피

가장 먼저 정한다. 폰트와 스케일이 화면의 인상을 8할 결정한다.

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--font-sans` | TBD | 본문 전체 |
| `--text-xs` ~ `--text-2xl` | TBD | 단계는 5~6개를 넘기지 않는다 |
| `--leading-tight` / `--leading-normal` | TBD | 제목 / 본문 |

- 폰트는 1종. 두 번째 폰트를 쓰고 싶어지면 굵기로 해결한다.
- 시스템 폰트 스택 그대로 쓰지 않는다 (기본값 = AI 티).

## 2. 스페이싱

| 토큰 | 값 |
|------|-----|
| `--space-1` ~ `--space-8` | TBD (4px 배수 스케일) |

- 스케일에 없는 값을 쓰지 않는다. `13px`, `27px` 같은 값이 나오면 스케일이 틀린 것이다.
- 위계는 테두리가 아니라 **여백 차이**로 만든다.

## 3. 색

타이포와 스페이싱이 끝난 뒤에 정한다. 색부터 정하면 그라데이션 함정에 빠진다.

| 토큰 | 값 | 용도 |
|------|-----|------|
| `--bg` / `--bg-subtle` | TBD | 배경 |
| `--fg` / `--fg-muted` | TBD | 본문 / 보조 텍스트 |
| `--border` | TBD | 구분선 |
| `--accent` | TBD | 강조 **1개만** |
| `--danger` | TBD | 삭제·에러 |

- 무채색 + 강조색 1개. 그라데이션 없음.
- 본문 대비 4.5:1 이상.

## 4. 모양 · 그림자

| 토큰 | 값 |
|------|-----|
| `--radius` | TBD (1~2단계) |
| `--shadow` | TBD (1단계면 충분) |

- 카드마다 테두리 + 그림자를 동시에 두지 않는다. 둘 중 하나.

## 5. 모션

| 토큰 | 값 |
|------|-----|
| `--duration-fast` / `--duration` | TBD (150~200ms) |
| `--ease` | TBD |

- 애니메이션은 UI·기능이 다 선 뒤 마지막에 얹는다 (PLAN.md Day 3 참고).
- 사용자 행동에 반응하는 것만. 알아서 움직이는 장식은 넣지 않는다.
- `prefers-reduced-motion` 존중.

---

## 규칙

1. 토큰은 CSS 변수로 `:root`에 한 번 선언하고, 컴포넌트는 변수만 참조한다.
2. 새 값이 필요하면 컴포넌트에 쓰지 말고 **이 파일에 먼저 추가**한다.
3. 스케일 단계를 늘리기 전에, 기존 단계로 해결되는지 먼저 본다.
