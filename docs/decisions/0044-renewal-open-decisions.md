# 0044. 글꼴은 Pretendard, 첫 탭은 "전체", 쓰던 글을 닫을 때는 묻는다

- 상태: 확정
- 날짜: 2026-09-14
- 대체: [0043](0043-soft-surface.md)의 남은 칸 셋, 같은 결정의 비용 "시스템 글꼴이라 운영체제마다 한글 모양이 다르다"

## 맥락

결정 0043이 리뉴얼 구현 전에 정할 것 셋을 남은 칸으로 남겼다. 사용자가 셋을 정했다.

## 선택지

**글꼴**

- A. 시스템 글꼴 그대로. 받는 파일이 없다. 기기마다 한글 모양이 다르고 Windows 맑은 고딕이 투박하다
- B. Pretendard(SIL OFL 1.1)를 직접 호스팅한다. 어느 기기에서나 같은 모양이다. 폰트 파일 용량이 붙는다

**첫 탭 이름** (`/`, 실제 정렬은 `lib/queries/post.ts`의 `listFeed`가 `created_at` 최신순)

- A. "추천" 유지. 바꿀 것이 없지만 누군가 골라준다고 기대하게 한다
- B. "전체" 또는 "최신". 보이는 그대로다

**글쓰기 시트를 닫을 때**

- A. 묻지 않고 닫는다. 실수로 닫으면 쓰던 글이 사라진다
- B. 쓰던 글이 있을 때만 버릴지 묻는다. 확인이 하나 늘어난다

## 결정

**B, B("전체"), B.** 사용자가 골랐다.

글꼴

- `next/font/local`로 Pretendard 가변 폰트 woff2 하나를 `app/fonts/`에 두고 불러온다. 라이선스 전문을 같은 폴더에 둔다
- npm 패키지를 설치하지 않는다. 파일 하나로 끝나고 AGENTS.md 규칙 7의 설치 확인이 필요 없다
- 대체 글꼴은 지금 시스템 스택이다. `next/font`가 대체 글꼴 크기를 맞춰 글자가 바뀌는 순간의 밀림을 줄인다
- 파일 용량을 리뉴얼 1단계 PR에서 재서 본문에 적는다. 첫 로드에 부담이 되면 그때 subset을 다시 묻는다

첫 탭

- 탭 라벨, 화면 제목, 문서 제목(`metadata.title`), 빈 화면과 404의 버튼 문구에서 "추천"을 "전체"로 바꾼다.
  "추천 둘러보기"는 "전체 글 둘러보기", "추천으로 돌아가기"는 "전체로 돌아가기"다
- 주소 `/`와 라우트 그룹 이름 `(feed)`는 그대로 둔다. 주소를 바꾸면 이미 공유된 링크가 깨진다

글쓰기 닫기

- 대상은 `ComposeDialog`를 쓰는 넷이다. 게시글 작성, 게시글 수정, 댓글, 답글
- 물을 조건은 "보낼 수 있는 상태"와 같다. 공백뿐이거나 처음 값과 같으면 묻지 않고 닫는다 ([결정 0042](0042-submit-guard.md)의 조건을 그대로 쓴다)
- 닫는 모든 길에 같이 건다. 취소 버튼, 바깥 누르기, Esc, 모바일 시트 끌어내리기
- 확인은 작은 모달이다. 제목 "작성 중인 글을 버릴까요?", 버튼 secondary "계속 쓰기"와 danger "버리기". 포커스는 "계속 쓰기"에 먼저 둔다
- 보내는 중에는 닫기 자체가 막혀 있으므로 묻지 않는다
- 프로필 편집은 대상이 아니다. 사용자가 고른 범위가 글쓰기다

## 비용

- 글꼴 파일이 모든 페이지 첫 로드에 붙는다. 용량은 1단계에서 측정 전까지 모른다
- "추천"이 코드 9곳(파일 8개)에 있어 리뉴얼 2, 4, 6단계가 나눠 고친다
- 닫기 확인이 radix `Dialog`의 닫힘 이벤트를 가로채야 한다. 시트 끌어내리기는 닫힘을 취소할 수 있게 만들어야 한다
