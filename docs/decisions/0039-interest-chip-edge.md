# 0039. 관심사 칩은 바깥 끝을 프로필 컬럼에 맞춘다

- 상태: 확정
- 날짜: 2026-09-14
- 대체: [0038](0038-interest-chip-fill.md)의 "목록을 12px 당겨 칩 글자를 컬럼 끝에 맞춘다"

## 맥락

결정 0038은 칩 글자를 별명, 소개, 팔로워와 같은 세로줄에 세우려고 목록을 `-ml-3` 당겼다.
사용자가 화면에 세로선을 그어 보니 칩의 회색 채움이 선 밖으로 튀어나와 오히려 정렬이 깨져 보였다.
알약 모양은 채움 끝과 글자 사이에 안쪽 여백이 있어 둘을 동시에 한 선에 맞출 수 없다.

## 선택지

- A. 칩 바깥 끝을 컬럼 끝에 맞춘다. 칩 글자는 12px 안쪽에서 시작한다. 레퍼런스(Threads) 프로필과 같다
- B. 칩을 없애고 글자만 둔다. 모든 글자가 한 선에 서지만 관심사가 소개와 덜 구분된다
- C. 0038 그대로 글자를 맞추고 채움을 밖으로 낸다. 사용자가 짚은 문제다

## 결정

**A.** 사용자가 "칩 바깥 끝을 선에 맞춰야 정렬된다"고 했다.

- `InterestChips` 목록의 `-ml-3`을 뺀다. 채움 모양(`bg-background`)은 0038 그대로다

## 비용

- 칩 글자는 다른 줄 글자보다 12px 안쪽에서 시작한다
