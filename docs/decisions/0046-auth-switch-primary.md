# 0046. 인증 화면의 건너가는 글자를 primary로 칠한다

- 상태: 확정
- 날짜: 2026-09-14
- 대체: [0034](0034-auth-responsive.md)의 "건너가는 줄은 `fg-muted` 문구와 `fg` 600 글자 버튼" 중 글자 버튼의 색과 굵기

## 맥락

리뉴얼 3단계에서 로그인·회원가입 화면을 `docs/DESIGN.md` 명세로 옮겼다. 건너가는 줄("처음 오셨나요? 회원가입하기")의
누르는 글자는 결정 0034가 `fg` 600으로 정해 두었다. 0034가 그렇게 정한 이유는 "파랑은 포커스 링에만 쓴다"(결정 0015)였다.
결정 0043이 `primary`를 동작 색으로 넓혔지만 0034의 이 줄은 대체하지 않았다. DESIGN.md 원칙 4는 누를 수 있는 것을
알약, 채움 버튼, `primary` 글자 셋 중 하나로 보이게 하라고 한다. PR 리뷰가 두 문서의 어긋남을 짚었다.

## 선택지

- A. `primary` 700. DESIGN.md 원칙 4와 ghost 버튼(`primary` 글자)과 같다. 0034의 전제(0015)는 0043이 이미 걷었다
- B. `fg` 600 유지. 0034 그대로다. 원칙 4의 세 모양 어디에도 들지 않아 누를 수 있어 보이지 않는다

## 결정

**A.** 작업 중 사용자가 골랐다. `components/auth/AuthPanels.tsx`의 건너가는 글자가 `text-primary font-bold`다.

- 문구(`fg-muted`)와 자리(768px 미만 바닥 가운데, 이상 폼 아래 선 밑)는 0034 그대로다
- 누를 자리를 넓히는 `-m-1 p-1`도 0034 그대로다

## 비용

- 한 줄에 `fg-muted`와 `primary` 두 색이 선다. 0034가 피하려던 파랑이 인증 화면에 하나 더 생긴다
