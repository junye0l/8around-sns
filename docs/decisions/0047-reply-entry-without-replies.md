# 0047. 답글이 없는 댓글에도 답글 화면으로 가는 글자를 둔다

- 상태: 확정
- 날짜: 2026-09-15
- 대체: `docs/DESIGN.md` 게시글 상세의 "답글이 있으면 '답글 N개 보기' 한 줄만 둔다" 중 답글이 없을 때

## 맥락

심사 시나리오 E2E를 짜면서 댓글에 첫 답글을 다는 경로를 코드에서 따라갔다.
게시글 상세의 댓글 행은 답글이 있을 때만 `/comment/[id]`로 가는 링크를 그렸다(`components/comment/CommentThread.tsx`).
답글이 0개인 댓글에는 작성자 이름 링크 말고 누를 곳이 없어, 주소를 직접 치지 않으면 첫 답글을 달 수 없었다.

리뉴얼 전에는 댓글마다 말풍선 숫자(`CommentCount`)가 답글 0개여도 답글 화면으로 이어졌다.
리뉴얼 5단계(PR #98)가 `docs/DESIGN.md`의 "말풍선 숫자 링크를 따로 두지 않는다"를 따르면서 그 진입점이 같이 사라졌다.
요구 기능인 대댓글이 화면에서 막힌 상태였다.

## 선택지

**A. 답글이 없으면 같은 자리에 "답글 달기" 글자를 둔다**
- 명세의 "`primary` 글자 한 줄"을 그대로 쓰고 빈 경우만 채운다
- 댓글 행이 모두 한 줄씩 길어진다

**B. 댓글 행 전체를 링크로 만든다**
- 누를 곳이 넓다
- 행 안의 작성자 링크, 더 보기 메뉴와 겹쳐 링크 안에 링크가 생긴다

**C. 화면은 두고 E2E만 주소를 직접 연다**
- 테스트는 통과하지만 사용자는 여전히 첫 답글을 달 수 없다

## 결정

**A.** 사용자가 골랐다.

- 답글 행(댓글 상세의 답글 목록)에는 두지 않는다. 1뎁스가 끝이라 갈 곳이 없다
- 게시글 상세 로딩 스켈레톤의 댓글 행에 같은 줄의 자리를 더한다. 답글 목록 스켈레톤에는 더하지 않는다

## 비용

- 댓글이 많은 글은 행마다 한 줄씩 길어져 한 화면에 보이는 댓글 수가 줄어든다
