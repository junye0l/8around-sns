# 0035. 펼친 레일은 반투명과 흐림으로 뒤 본문을 비친다

- 상태: 대체됨 → [0041](0041-soft-surface.md)
- 날짜: 2026-09-14

## 맥락

결정 0033 이후 태블릿 폭(768~1023px)에서도 레일이 호버나 키보드 포커스로 240px까지 펼쳐진다.
820px에서 카드가 x=92부터 시작해 펼친 레일이 컬럼 왼쪽 약 148px을 불투명 `bg-background`로 덮었다.
1280px에서는 카드가 x=320부터라 겹치지 않는다. 사용자가 덮인 본문이 살짝 보이게 하자고 했다.

## 선택지

- A. 반투명만(`bg-background/90`). 한 줄이지만 뒤 글자가 선명하게 비쳐 레일 문구와 겹친다
- B. 반투명과 흐림(`bg-background/80` + 흐림 12px). 뒤는 형태만 보이고 레일 문구는 또렷하다. 문서에 없는 효과다
- C. 불투명은 두고 오른쪽에 `hairline` 1px. 뒤가 보이지 않는다

## 결정

**B.** 사용자가 골랐다.

- 흐림 값은 `app/globals.css`의 `--blur-rail`(12px, Tailwind `blur-md`와 같은 값)에 로컬 확장으로 둔다
- 불투명도는 결정 0015가 버튼 hover에 쓴 방식처럼 기존 색에 `/80`만 붙인다. 새 색을 만들지 않는다

## 비용

- `backdrop-filter`는 레일이 펼쳐진 동안 뒤를 매 프레임 다시 그린다. 펼친 순간에만 켜진다
