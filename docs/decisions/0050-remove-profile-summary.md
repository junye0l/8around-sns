# 0050. 오른쪽 칸의 내 프로필 요약을 없애고 뼈대를 두 칸으로 줄인다

- 상태: 확정
- 날짜: 2026-09-15

## 맥락

1280px 이상에서 뼈대가 오른쪽 300px 칸에 내 프로필 요약 카드를 두었다. 소프트 서피스 리뉴얼(결정 0043, `ef53b3d`)과 함께 들어왔다.
레이아웃이 그려서 모든 화면에 붙는다.

사용자가 내 프로필 화면에서 가운데 헤더 카드와 오른쪽 카드가 같은 내용이라고 짚었다.
카드의 아바타, 이름, 소개, 팔로워와 팔로잉 수, 관심사는 전부 내 프로필 헤더에 있고, 카드가 가는 링크는 왼쪽 메뉴의 "프로필"과 같다.

## 선택지

**A. 내 프로필 화면에서만 카드를 서서히 감춘다**
- 중복은 사라진다. 칸 폭을 남기면 가운데 칸이 밀리지 않는다
- 만들어 보니 카드는 주소가 바뀌는 순간 사라지고 가운데 칸은 스켈레톤, 내용 순서로 전환 없이 바뀌어 타이밍이 어긋났다
- 맞추려면 모든 화면 전환에 움직임을 넣어야 하는데 `docs/DESIGN.md` 움직임 절에 화면 전환 규칙이 없다

**B. 카드를 없애고, 1024px 이상 뼈대를 메뉴와 가운데 칸 두 칸으로 둔다**
- 1279px 이하에서 이미 쓰던 모양이라 새로 정할 값이 최대 폭 하나다
- 넓은 화면에서 양옆이 빈다

**C. 그대로 둔다**
- 변경이 없다. 중복이 남는다

최대 폭은 두 가지를 봤다. 1180px을 두고 오른쪽을 비우면 가운데 칸이 왼쪽으로 치우친다.
메뉴 220px, 칸 사이 24px, 가운데 600px, 좌우 여백 24px을 더한 892px로 줄이면 묶음이 화면 가운데에 선다.

## 결정

**B, 최대 폭 892px.** 사용자가 골랐다.

- `components/profile/ProfileSummary.tsx`를 지웠다
- 892px은 새 값이 아니라 이미 있는 값의 합이다. `app/(main)/layout.tsx`의 `max-w-223`이다

## 비용

- 1024 ~ 1279px에서도 최대 폭이 892px로 걸려, 그 폭에서 메뉴가 전보다 안쪽에 선다
- 넓은 화면에서 양옆 여백이 커진다
