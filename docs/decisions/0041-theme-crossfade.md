# 0041. 테마를 바꿀 때 화면 전체를 한 장으로 겹쳐 넘긴다

- 상태: 확정
- 날짜: 2026-09-14

## 맥락

사용자가 테마 전환이 번쩍이듯 바뀌고, 그 순간 레일의 글쓰기 `+` 칸 색이 따로 보인다고 했다.
매 프레임 계산된 색을 기록해 보니 바탕, 카드, 제목줄은 한 프레임에 바뀌는데
`transition-colors`가 붙은 글쓰기 버튼과 레일 링크는 150ms 동안 옛 색에서 따라왔다.
어두워진 화면 위에 버튼 채움만 밝은 회색으로 남은 것이 사용자가 본 칸이다.

## 선택지

- A. View Transitions API로 옛 화면과 새 화면을 겹쳐 흐리게 넘긴다. 겹치는 동안 요소별 전환은 끈다
- B. 요소별 전환만 끄고 한 프레임에 바꾼다. 튀는 칸은 사라지지만 번쩍이는 느낌은 그대로다
- C. 모든 요소에 같은 색 전환을 건다. 테두리, 글자, 채움, 그림자 없는 면까지 빠짐없이 걸어야 하고 하나만 빠져도 다시 튄다

## 결정

**A.** `components/layout/MoreMenu.tsx`의 `applyTheme`이 `document.startViewTransition`으로 `data-theme`을 바꾸고,
그동안 `data-theme-switching` 속성으로 요소별 `transition`을 끈다. 길이와 이징은 `--motion-standard`, `--ease-standard`다.

## 비용

- API를 모르는 브라우저는 B처럼 한 프레임에 바뀐다
- 겹치는 동안(250ms) 화면은 두 장의 사진이라 그 사이 호버 색 변화는 보이지 않는다
- 동작 줄이기 설정에서는 motion 토큰이 0ms라 겹치지 않고 바로 바뀐다
